Privacy

Haze sells patterns, not identities

Privacy is the foundation, not a feature. Data buyers never learn who the wallet owner is.

Wallet addresses are never exposed. Profiles use random identifiers only.

No transaction hashes, no counterparties, no specific positions, no exact amounts. Only computed behavioral patterns.

You control exactly which data categories are shared. Exclude stock data, specific protocols, or time periods.

Aggregated cohort responses by default. Buyers query batches of anonymized profiles, never individuals.

Optional ZK proof layer verifies profile authenticity without revealing which wallet generated it.

Delete your profile and all data with one tap. Permanent, immediate, irreversible.
